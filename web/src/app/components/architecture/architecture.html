2 · Two-layer Evaluator

⚡ Deterministic Layer
Pure Python · No LLM · <15ms
🔒 clinical-scope-lock — only authorised tools
🩹 pii-boundary — REDACT PHI before external calls
⚖ confidence-gate — escalate <0.70
🌍 lingua-language-match — output lang must match input
🔤 lingua-script-guard — Unicode block validation
🚫 no-public-actions — block send_email, post_*, etc.
🧠 Hybrid Layer (Gemma 4)
gemma4:e4b via Ollama · think:false · 200–500 tokens
💊 contraindication-check — drug-allergy, drug-drug
📋 draft-only-mode — autonomous action detection
📚 lingua-terminology-lock — target-language clinical terms
Live grounding: 📡 openFDA SPL 📚 PubMed
