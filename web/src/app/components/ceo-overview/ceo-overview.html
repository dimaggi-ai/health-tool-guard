The Problem

AI agents act without governance

AI agents are making autonomous decisions in critical environments — transferring funds, triaging patients, grading students. Every action is a tool call. Most tool calls execute with nothing between the agent's decision and the real-world consequence.

The gap is not intelligence. The models are capable. The gap is trust. Without a governance layer, organisations either block adoption entirely or keep agents trapped in low-value pilot mode.

The Answer

Tool Guard: pre-execution policy enforcement

Tool Guard intercepts every tool call, evaluates it against configurable governance rules using a hybrid engine — deterministic rules for speed, Gemma 4 model-assisted reasoning for ambiguous cases — makes a decision, generates a human-readable explanation, and records every step in a tamper-evident audit chain.

How It Works

The Tool Guard pipeline

01
Intercept
SDK wraps every agent tool call into an ActionEnvelope with agent identity, parameters, timestamps, and modality metadata.
→
02
Evaluate
Fast deterministic rules run first (<12ms). Ambiguous cases route to Gemma 4 deep reasoning with full policy context (<800ms).
→
03
Decide
ALLOW, DENY, REDACT-AND-CONTINUE, ESCALATE, or FLAG. Redaction strips PII fields and lets the sanitised action proceed.
→
04
Explain
Gemma 4 generates a human-readable explanation for every decision — what happened, why, which policy mattered.
→
05
Audit
SHA-256 hash chain + HMAC signing. Every decision is immutably recorded and verifiable offline via CLI.
